# Payment (зарплата)

Короткое описание
- Класс `Payment` (файл `Payment.cs`) рассчитывает зарплату сотрудника за месяц.
- Поля класса: ФИО, оклад, год поступления, процент надбавки, процент подоходного налога, отработанные дни и рабочие дни в месяце.

Как считаются суммы
- Начисления: пропорциональная часть оклада за отработанные дни плюс надбавка.
  Формула: `basePay = Salary * DaysWorked / WorkingDaysInMonth`, `allowance = basePay * AllowancePercent/100`, `Accrued = basePay + allowance`.
- Удержания: 1% в пенсионный фонд + подоходный налог (значение поля `IncomeTaxPercent`).
  Формула: `Withheld = Accrued * 0.01 + Accrued * IncomeTaxPercent/100`.
- На руки: `Net = Accrued - Withheld`.

Методы
- `CalculateAccrued()` — вычисляет и записывает `AccruedAmount`.
- `CalculateWithheld()` — вычисляет и записывает `WithheldAmount`.
- `CalculateNet()` — возвращает `AccruedAmount - WithheldAmount` (при необходимости вызывает предыдущие методы).
- `CalculateExperience()` — возвращает целое количество полных лет стажа (текущий год - `HireYear`).

Пример использования
- Файл `Program.cs` содержит пример создания `Payment` и вывода результатов в консоль.

Примечания
- Все денежные вычисления округляются до копеек (`Math.Round(..., 2)`).
- НДФЛ считается как 13% от начисленной суммы.
- Пенсионный фонд считается как 1% от начисленной суммы.
- При некорректных данных методы расчета выбросят `ArgumentException`.
